# Tutu

**Тату на твоєму 3D-тілі.** Обираєш одне з 10 реалістичних базових тіл і підлаштовуєш зріст, вагу, м'язи (або, додатково, скануєш себе iPhone з LiDAR) → виділяєш кистю, де буде тату →
ділянка автоматично розгортається в плаский шаблон → малюєш або генеруєш ескіз ШІ →
бачиш його на тілі в 3D → друкуєш трафарет у реальному розмірі 1:1.

План продукту й етапи: [docs/PLAN.md](docs/PLAN.md).
Аналіз користувачів і генераторів: [docs/RESEARCH.md](docs/RESEARCH.md).
Архітектура і захист коду: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

> Пропрієтарний код, усі права захищено — див. [LICENSE](LICENSE).

## Структура

| Папка | Що всередині |
|---|---|
| `web/` | Редактор: TypeScript + Three.js + Vite. 3D-в'юпорт, кисть виділення, LSCM-розгортка, шари, туш, експорт трафарету |
| `server/` | Python FastAPI: реалістичні тіла (MakeHuman CC0), скани, проєкти, генерація ескізів (OpenAI Images або офлайн mock) |
| `ios/` | SwiftUI: базові тіла + вбудований редактор; LiDAR-сканування — додатково |
| `docs/` | План і рішення |

## Швидкий старт

```bash
# 1. Бекенд
cd tutu/server
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 2. Редактор (у другому терміналі)
cd tutu/web
npm install
npm run dev          # http://localhost:5173, /api проксіюється на :8000
```

Продакшн-варіант: `npm run build` у `web/`, після чого бекенд сам віддає редактор на `http://localhost:8000/`.

Або все одразу в Docker: `docker compose up --build` → http://localhost:8000

Моделі тіла будуються з `server/app/body/assets/makehuman_body.npz` (ресурси MakeHuman, CC0).
Перезібрати пакет: `python server/scripts/build_body_assets.py <mpfb2>/src/mpfb/data`.

### Версія без сервера (claude.ai)

Редактор уміє працювати повністю в браузері: тіла рахуються локально, ескізи малює Claude (SVG),
проєкти зберігаються в браузері. Так він опублікований як сторінка claude.ai:
https://claude.ai/artifact/KBtKNrK2z9rW6suxdHvqXL (приватна, відкривається з вашого акаунта).

```bash
python server/scripts/export_body_bin.py   # дані тіла для браузера
cd web && npm run build:artifact           # -> web/dist-artifact/
```

### Постійне посилання (безкоштовно, Render)

Покрокова інструкція з FLUX: [docs/DEPLOY.md](docs/DEPLOY.md). Генерація на своїй відеокарті: [docs/LOCAL_GPU.md](docs/LOCAL_GPU.md).

1. Відкрийте https://render.com/deploy?repo=https://github.com/vladimir0y/1234 і увійдіть через GitHub
   (для приватного репозиторію дайте Render доступ до `1234`).
2. Натисніть **Apply** — Render збере `tutu/Dockerfile` за `render.yaml`.
3. Через 5–10 хв з'явиться адреса `https://tutu-xxxx.onrender.com`.

Безкоштовний сервер засинає без відвідувань (перше відкриття ~1 хв), а збережені проєкти
зникають при перезапуску. Для кращих ескізів додайте в Render → Environment `CLOUDFLARE_ACCOUNT_ID`
і `CLOUDFLARE_API_TOKEN` (див. [docs/RESEARCH.md](docs/RESEARCH.md)).

### ШІ-генерація

Без налаштувань працює офлайн-заглушка (для розробки). Безкоштовні справжні ескізи —
**Cloudflare Workers AI (FLUX.1 schnell, ~200 зображень/день безкоштовно)**:

```bash
export CLOUDFLARE_ACCOUNT_ID=...
export CLOUDFLARE_API_TOKEN=...
# опційно: OPENAI_API_KEY (преміум), POLLINATIONS_KEY, AI_HORDE_API_KEY
```

Сервер пробує генератори по черзі, а якщо один недоступний — бере наступний, і очищає
кожен результат під тату (прозорий фон, обрізка, чорна лінія або колір).
Порівняння сервісів і покрокове підключення: [docs/RESEARCH.md](docs/RESEARCH.md).

## Як користуватися редактором

1. **Модель** — стать, одна з 5 статур, повзунки зросту, ваги, м'язів, грудей; фокус камери на потрібну частину тіла; додатково — свій скан OBJ/GLB/PLY/STL.
2. **Виділити** — проведіть кистю по тілу або оберіть **готову зону** (браслет, кільце на плечі, стегні, гомілці — кільце автоматично розрізається швом). Розгортка з'являється праворуч, з розміром у см і оцінкою якості.
3. **Шари** — додайте зображення або згенеруйте ескіз. Тягніть, масштабуйте кутами, обертайте за круглу ручку.
   «Трафарет» перетворює картинку на чорну лінію без фону.
4. **Пензель / Гумка** — малюйте тушшю прямо в розгортці; на 3D-тілі видно одразу.
5. **Експорт** — PNG-трафарет 300/600 DPI у реальному розмірі з лінійкою 5 см (друк з масштабом 100%, перевірте лінійкою).
   Перемикачі «загоєне» і тон шкіри показують, як тату виглядатиме в житті.
6. **Зберегти** — проєкт на сервері, посилання `?project=…` відкриває його знову.
