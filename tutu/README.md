# Tutu

**Тату на твоєму 3D-тілі.** Обираєш одне з 10 реалістичних базових тіл і підлаштовуєш зріст, вагу, м'язи (або, додатково, скануєш себе iPhone з LiDAR) → виділяєш кистю, де буде тату →
ділянка автоматично розгортається в плаский шаблон → малюєш або генеруєш ескіз ШІ →
бачиш його на тілі в 3D → друкуєш трафарет у реальному розмірі 1:1.

План продукту й етапи: [docs/PLAN.md](docs/PLAN.md).
Архітектура і захист коду: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

> Пропрієтарний код, усі права захищено — див. [LICENSE](LICENSE).

## Структура

| Папка | Що всередині |
|---|---|
| `web/` | Редактор: TypeScript + Three.js + Vite. 3D-в'юпорт, кисть виділення, LSCM-розгортка, шари, туш, експорт трафарету |
| `server/` | Python FastAPI: реалістичні тіла (MakeHuman CC0), скани, проєкти, генерація ескізів (OpenAI Images або офлайн mock) |
| `ios/` | SwiftUI: базові тіла + вбудований редактор; LiDAR-сканування — додатково |
| `docs/` | План і рішення |

## Швидкий старт

```bash
# 1. Бекенд
cd tutu/server
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 2. Редактор (у другому терміналі)
cd tutu/web
npm install
npm run dev          # http://localhost:5173, /api проксіюється на :8000
```

Продакшн-варіант: `npm run build` у `web/`, після чого бекенд сам віддає редактор на `http://localhost:8000/`.

Або все одразу в Docker: `docker compose up --build` → http://localhost:8000

Моделі тіла будуються з `server/app/body/assets/makehuman_body.npz` (ресурси MakeHuman, CC0).
Перезібрати пакет: `python server/scripts/build_body_assets.py <mpfb2>/src/mpfb/data`.

### ШІ-генерація

Без ключа працює офлайн-генератор орнаментів (для розробки). Для справжніх ескізів:

```bash
export OPENAI_API_KEY=sk-...
export TUTU_IMAGE_PROVIDER=openai     # або auto (за замовчуванням)
```

### Тести

```bash
cd tutu/server && pytest -q
cd tutu/web && npm test
```

## Як користуватися редактором

1. **Модель** — стать, одна з 5 статур, повзунки зросту, ваги, м'язів, грудей; фокус камери на потрібну частину тіла; додатково — свій скан OBJ/GLB/PLY/STL.
2. **Виділити** — проведіть кистю по тілу. Розгортка з'являється праворуч, з розміром у см і оцінкою якості.
3. **Шари** — додайте зображення або згенеруйте ескіз. Тягніть, масштабуйте кутами, обертайте за круглу ручку.
   «Трафарет» перетворює картинку на чорну лінію без фону.
4. **Пензель / Гумка** — малюйте тушшю прямо в розгортці; на 3D-тілі видно одразу.
5. **Експорт** — PNG-трафарет 300/600 DPI у реальному розмірі (друк з масштабом 100%).
6. **Зберегти** — проєкт на сервері, посилання `?project=…` відкриває його знову.
