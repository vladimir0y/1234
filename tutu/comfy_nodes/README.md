# Вузли Tutu для ComfyUI

Підготовка зображень під розгортку тіла з Tutu прямо в ComfyUI.

**Встановлення:** скопіюйте папку `tutu/comfy_nodes` у `ComfyUI/custom_nodes/tutu` і перезапустіть ComfyUI.
Залежності (numpy, Pillow) вже є в ComfyUI.

| Вузол | Що робить |
|---|---|
| **Tutu: полотно тіла** | Розгортка тіла: `wrap_torso` (навколо тулуба — спина, бік, груди), `front_back_torso`, `front_back_body`. Видає силует, маску тіла, ширину й висоту для генерації |
| **Tutu: маска зони** | Маска частини тіла (`back`, `chest`, `right_side`, `lower_back`, `dragon_area`…) з м'яким краєм — для домальовування без шва |
| **Tutu: розкладка композиції** | Кольорові зони «де що лежить» для img2img (пресет `face_back_dragon_chest`: обличчя на спині, голова дракона на грудях, тіло дракона довкола) |
| **Tutu: перегляд на тілі** | Показує картинку як фарбу на шкірі силуету |
| **Tutu: зберегти для редактора** | PNG у `ComfyUI/output/tutu/` (поза тілом прозоро) — завантажити в Tutu на полотно «навколо тулуба» |

**Готова схема:** `tutu_dragon_face_pipeline.json` (перетягніть у ComfyUI):
розкладка → вся сцена (img2img 0,82) → домальовування дракона за маскою зони (Differential Diffusion) → вирівнювання (0,3) → перегляд на тілі → збереження для редактора.
Міняйте сіди в трьох KSampler, щоб перебирати варіанти. Рецепт і налаштування під 4 ГБ: `tutu/docs/PROJECT_BRIEF.md`.
