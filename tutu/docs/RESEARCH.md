# Tutu — аналіз: користувачі та генератори зображень

Листопад 2026.

## 1. Що потрібно користувачам

### Клієнт, який хоче тату

| Потреба | Що є в Tutu | Що далі |
|---|---|---|
| «Як це виглядатиме саме на мені?» | 10 реалістичних тіл, зріст/вага/м'язи/груди, **6 тонів шкіри** | Підгонка під заміри (обхвати в см), фото → тіло |
| Ідеї, якщо немає ескізу | ШІ-генерація, 14 стилів, **2–4 варіанти** за раз, швидкі мотиви | Генерація під форму ділянки (маска), «ще схожі» |
| Писати українською | Автопереклад промпту uk→en (через Cloudflare m2m100) | Підказки до промпту |
| Браслет, рукав, тату навколо ноги | **Готові зони** + автоматичний шов: кільце → точна смуга | Вибір, де пройде шов (з внутрішнього боку руки) |
| Розуміти, як тату постаріє | Перемикач **«загоєне»** (м'якші лінії, менший контраст) | Симуляція через 5–10 років, розпливання тонких ліній |
| Показати майстру або друзям | Збереження проєкту, посилання `?project=` | Публічне посилання лише для перегляду, PDF |

### Тату-майстер

| Потреба | Що є в Tutu | Що далі |
|---|---|---|
| Трафарет під конкретне тіло | Розгортка ділянки, PNG **1:1, 300/600 DPI**, **лінійка 5 см** для перевірки друку | PDF для принтера трафаретів (термопапір) |
| Перенести свій ескіз | Імпорт зображення, **трафаретний фільтр з порогом лінії** | SVG/векторизація, PSD |
| Дзеркальні й симетричні елементи | **Дзеркало й копія шару** | Інструмент симетрії відносно осі тіла |
| Чистий результат від ШІ | Сервер **очищає кожне зображення**: прибирає фон, рамки, обрізає, робить чорну лінію або лишає колір | Векторизація ліній |
| Не втратити роботу | **Ctrl+S**, попередження про незбережене | Автозбереження, версії |

### Що вирішили зробити першочергово (зроблено в цьому оновленні)

1. Безкоштовні генератори з чергою, запасними варіантами й очищенням результату.
2. Варіанти й галерея: користувач обирає, а не погоджується на єдиний результат.
3. Кільцеві зони (браслети, рукави) — один із найпоширеніших запитів, раніше не працював.
4. Тон шкіри та «загоєний» вигляд — реалістичність примірки.
5. Інструменти майстра: дзеркало, копія, поріг трафарету, лінійка друку.

## 2. Генератори зображень: порівняння

Перевірено наживо з сервера Tutu, де це було можливо.

| Сервіс | Ціна | Якість для тату | Швидкість | Ліцензія/умови | Висновок |
|---|---|---|---|---|---|
| **Cloudflare Workers AI** — FLUX.1 [schnell] | **Безкоштовно**: 10 000 «нейронів»/день ≈ 200+ зображень; далі $0.011 / 1000 нейронів | Добра: чисті лінії, слухається «black ink» | 2–5 с | Модель Apache-2.0 → **комерційно можна** | **Основний безкоштовний.** Потрібен безкоштовний акаунт Cloudflare |
| **Pollinations.ai** без ключа | Безкоштовно | **Погана**: водяний знак, слабка модель (SANA), ігнорує «чорна лінія» | 1 зображення / 45 с на IP | — | Перевірено: непридатно для продукту, лише для розробки |
| **Pollinations.ai** з ключем | Стартові безкоштовні кредити, далі передоплата | FLUX без водяного знака | секунди | Умови сервісу | Запасний варіант |
| **AI Horde** (Stable Horde) | Повністю безкоштовно (волонтерські GPU) | Добра (SDXL: AlbedoBase, Juggernaut) | **Анонімно ~10 хв черги** (перевірено), з ключем швидше | Промпти бачать волонтери; ліцензії моделей різні | Лише фонові задачі; не для приватних даних |
| **Hugging Face Inference** | З жовтня 2026 безкоштовних кредитів немає (лише PRO $2/міс) | — | — | — | Не підключали |
| **OpenAI gpt-image** | Платно (центи за зображення) | Найкраща: прозорий фон, точно слухається | 10–40 с | Комерційно можна | Преміум-режим для платних тарифів |
| **Власний FLUX.1 schnell** (diffusers/ComfyUI на GPU) | Лише оренда GPU | Як у Cloudflare, плюс тонке налаштування під тату (LoRA) | 1–3 с | Apache-2.0 | Коли генерацій стане багато (див. ARCHITECTURE) |

Не підходять для комерції без окремої ліцензії: FLUX.1 [dev] (лише некомерційне використання).

### Як це влаштовано в Tutu

```
POST /api/generate  →  job_id одразу
   ├─ переклад uk→en (Cloudflare m2m100, якщо налаштовано)
   ├─ для кожного варіанта: ланцюжок провайдерів
   │     cloudflare → openai → pollinations → horde   (якщо налаштовані)
   │     ліміт або помилка → наступний провайдер
   └─ очищення: фон заливкою від країв → прозорий, рамки прибрано,
      обрізка по малюнку, режим «чорна лінія» або «колір» (за стилем)
GET /api/jobs/{id}  →  статус, готові варіанти з'являються по одному
```

### Як підключити безкоштовний Cloudflare (5 хвилин)

1. Зареєструйтесь на cloudflare.com (безкоштовний план, картка не потрібна).
2. Dashboard → **AI → Workers AI** → *Use REST API*.
3. Створіть **API Token** з дозволом *Workers AI: Read/Edit*. Скопіюйте **Account ID**.
4. Додайте змінні середовища серверу:
   ```bash
   CLOUDFLARE_ACCOUNT_ID=...
   CLOUDFLARE_API_TOKEN=...
   ```
5. Перезапустіть сервер — у редакторі з'явиться «FLUX.1 schnell (Cloudflare)».

Інші змінні: `OPENAI_API_KEY`, `POLLINATIONS_KEY`, `AI_HORDE_API_KEY` (або `TUTU_HORDE=1` для анонімного),
`TUTU_POLLINATIONS_ANON=1` (лише розробка), `TUTU_IMAGE_PROVIDERS=cloudflare,openai` — свій порядок.
