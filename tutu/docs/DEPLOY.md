# Свій сайт Tutu з FLUX — покроково (~10 хвилин, безкоштовно)

Результат: постійна адреса `https://tutu-xxxx.onrender.com`, де кнопка «Згенерувати»
малює **растрові реалістичні картинки FLUX** (а не векторні ескізи, як на сторінці claude.ai).

## Крок 1. Ключ Cloudflare для FLUX (5 хв)

1. Зареєструйтесь на https://dash.cloudflare.com/sign-up (картка не потрібна).
2. Відкрийте https://dash.cloudflare.com → у лівому меню **AI → Workers AI**.
   Натисніть **Use REST API**.
3. Скопіюйте **Account ID** — це рядок з 32 символів.
4. На тій самій сторінці натисніть **Create a Workers AI API Token** → **Create API Token**.
   Скопіюйте токен одразу: другий раз його не покажуть.

Безкоштовно це приблизно 100–200 картинок на день. Ліміт оновлюється щодоби.

## Крок 2. Сайт на Render (5 хв + ~10 хв збірки)

1. Відкрийте https://render.com/deploy?repo=https://github.com/vladimir0y/1234
   і увійдіть через **GitHub**.
   Якщо репозиторій приватний, Render попросить доступ — дозвольте йому репозиторій `1234`.
2. Render покаже сервіс **tutu** і два порожні поля:
   - `CLOUDFLARE_ACCOUNT_ID` — вставте Account ID;
   - `CLOUDFLARE_API_TOKEN` — вставте токен.
3. Натисніть **Deploy Blueprint** / **Apply**. Збірка триває 5–10 хвилин.
4. Адреса сайту з'явиться вгорі сторінки сервісу: `https://tutu-xxxx.onrender.com`.

Якщо ключі не вставили одразу: **Render → tutu → Environment → Add Environment Variable**,
потім **Save, rebuild and deploy**.

## Крок 3. Перевірка

- `https://tutu-xxxx.onrender.com/api/providers` має містити `"cloudflare"` з `"available": true`.
- У редакторі:
  1. виділіть ділянку;
  2. «Стиль» → **Художнє зображення**, **Реалізм ч/б** або **Реалізм кольоровий**;
  3. у списку генераторів (поруч зі стилем) оберіть **FLUX.1 schnell (Cloudflare)**;
  4. натисніть **Згенерувати**.

  Українською писати можна: промпт перекладається автоматично. Картинка підганяється
  під пропорції виділеної ділянки.
- Меню **«Мої проєкти» → «Приклад: змія спереду + портрет на спині»** є і тут.

## Що варто знати

- Безкоштовний сервер Render **засинає** після 15 хвилин без відвідувань.
  Перше відкриття після цього триває близько хвилини.
- Збережені на сервері проєкти **зникають** при перезапуску безкоштовного сервера.
  Важливе зберігайте як картинку: «Трафарет 1:1 (PNG)» і «Знімок 3D».
- Код на сервері не видно відвідувачам: вони отримують лише зібраний мінімізований JS.
  Сам репозиторій зробіть приватним:
  **GitHub → Settings → General → Danger Zone → Change visibility → Private**.
- Запасні генератори без ключів:
  - якщо Cloudflare вичерпав ліміт, сервер переходить на Pollinations (з водяним знаком);
  - щоб додати AI Horde (безкоштовно, але черга 5–20 хв), встановіть `TUTU_HORDE=1`.
